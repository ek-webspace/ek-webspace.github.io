EH SANKHANI.CV - UPLOAD GUIDE

Upload all files and the assets folder to the ROOT of your ek-webspace.github.io repository.
Do not rename index.html, style.css, or script.js.

ADD YOUR PHOTO
1. Rename your photo to: profile.jpg
2. Put it inside the assets folder.
3. Recommended: vertical 4:5 ratio, at least 1200 x 1500 px.

ADD LINKS LATER
Open index.html and search for: disabled-link
Replace href="#" with the real URL, then remove class="disabled-link" and the <span>soon</span> text.

ADD CV LATER
Put cv.pdf in the assets folder. Change the CV href to assets/cv.pdf and add target="_blank".

OPTIONAL OG IMAGE
Add assets/og-cover.jpg, recommended size 1200 x 630 px, for social sharing previews.
